## 🔧 Technical Details

### 🚀 Latest Features
- **Mapbox GL JS v3.13.0** - Latest version with enhanced 3D capabilities
- **WebGL 2** - Advanced rendering and performance
- **Standard Style** - Dynamic lighting and shadows
- **3D Models** - GLTF support for complex animations
- **Terrain & Elevation** - Real-world height data

### 🛠️ Built With
- [Mapbox GL JS](https://docs.mapbox.com/mapbox-gl-js/) - Interactive maps
- [Three.js](https://threejs.org/) - 3D graphics and animations
- [dat.GUI](https://github.com/dataarts/dat.gui) - Parameter controls
- [GLTF](https://www.khronos.org/gltf/) - 3D model format

## 🚀 Quick Start

1. **Clone the repository**
   ```bash
   git clone https://github.com/pratikyadav/maps.git
   cd maps
   ```

2. **Serve locally**
   ```bash
   # Using Python
   python3 -m http.server 8080
   
   # Using Node.js
   npx serve .
   ```

3. **Open your browser**
   ```
   http://localhost:8080
   ```

4. **Run tests** (optional)
   ```bash
   ./test-pages-simple.sh
   ```
